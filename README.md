# 小小職人體驗｜Taichung Experience Lab

台中親子職人體驗的公開網站。以米白、森林綠與陶土色建立一致的編輯式視覺，使用在地 SVG 線條圖示與工藝靜物主視覺。

## 頁面與功能
- `index.html`：常駐活動、活動分類與搜尋、活動詳情、合作與家長興趣表單、常見問題。
- `register.html`：活動選擇、家長與孩子資料、確認資料的三步驟流程。
- 桌面與手機自適應、鍵盤操作、焦點樣式、減少動態效果偏好支援。
- 表單可產生私訊文字；常駐活動與尚在媒合的方向有不同的行動提示。

## 本機預覽
不需要安裝前端套件。在專案目錄執行：

```sh
python -m http.server 4187 --bind 127.0.0.1
```

開啟 http://127.0.0.1:4187 。

## 維護
- 活動資料：`app.js`、`register.js` 頂部的 `activities`。更新活動時，請同步維護兩份資料。
- 共用視覺與版面：`style.css`；報名頁專用樣式：`register.css`。
- 共用圖示：`icons.js`，使用 `siteIcon(name)` 或 `<span data-icon="name"></span>`。
- 主視覺：`assets/hero-workshop.webp`，工藝意象圖，不代表實際活動現場。
- GitHub Pages 從 `main` 分支根目錄發布，所有資源採相對路徑。

## 活動與報名狀態
常駐活動的實際日期於報名後協調；尚未確認的合作職人、日期、費用、名額與場地，應清楚標示為待確認，避免把體驗方向誤認為正式場次。

`register.js` 的 `REGISTRATION_ENDPOINT` 預設為空。未設定接收端時，報名資料僅保存在使用者裝置，主辦方不會自動收到；頁面會明確說明狀態並提供複製資料功能。此視覺更新未新增後端服務。
